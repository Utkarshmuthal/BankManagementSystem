# Bank Management System

## Project Overview
The Bank Management System is a web-based application designed to manage banking operations through a frontend interface and a Java-based backend.

## Technologies Used
- **Backend:** Java, Spring Boot, Spring JDBC
- **Frontend:** JSP, CSS, JavaScript
- **Database:** PostgreySQL
- **Build Tool:** Maven
- **Version Control:** Git and GitHub

## Features
Include the features implemented in your project, such as:
- User registration and login
- Customer management
- Bank account management
- Deposit and withdrawal operations
- Transaction history
- Employee and admin dashboards

## Project Structure
- `BankingManagementSystemBackenduptochatbot/` — Backend application
- `BankingManagementSystemFrontenduptochatbot/` — Frontend application

## How to Run
1. Clone this repository.
2. Configure the database connection in the backend configuration.
3. Open the backend project in Spring Tool Suite or another compatible IDE.
4. Resolve Maven dependencies and run the Spring Boot application.
5. Open the frontend using the appropriate local web server or configured development environment.
6. Verify that the frontend connects to the running backend.
